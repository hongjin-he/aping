# 阿平 A-Ping — ISOM 2010 group project concept site

Static one-page site. No build step, no dependencies. Open `index.html` locally, or deploy to GitHub Pages.

- Bilingual: 繁體中文 / English (toggle in the top-right)
- Three ~30-second animated scene demos
- Light and dark themes follow the visitor's system setting

Concept stage only — the product does not exist, and every price on the page is a hypothesis to be tested.
